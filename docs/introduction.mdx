## Why AtoZAPI?

FastAPI revolutionized the Python backend ecosystem with two core ergonomics: **declarative runtime validation** and **instant interactive documentation at `/docs`**. 

Until now, teams using Node.js, Next.js, Go, or PHP had to choose between writing verbose JSDoc/Swagger YAML by hand, maintaining desynchronized specs, or stitching together incompatible libraries.

AtoZAPI bridges that gap:

<CardGrid cols={2}>
  <FeatureCard title="Zero Manual Swagger Writing" icon="code">
    Never write hundreds of lines of brittle OpenAPI YAML or JSDoc comments again. Your route definitions and schemas serve as the single source of truth.
  </FeatureCard>
  <FeatureCard title="Standardized HTTP 422 Errors" icon="shield">
    Every SDK emits the identical Pydantic-compatible validation payload: <code>{ "detail": [{ "loc": [...], "msg": "...", "type": "..." }] }</code>.
  </FeatureCard>
  <FeatureCard title="Instant Interactive /docs & /redoc" icon="browser">
    A single CLI command scans your code and boots up embedded Swagger UI and ReDoc servers at <code>http://localhost:8000/docs</code>.
  </FeatureCard>
  <FeatureCard title="Zero-Dependency Runtime Architecture" icon="cpu">
    Lightweight, deterministic validation designed for microservices and serverless runtimes without heavy dependencies.
  </FeatureCard>
</CardGrid>

## Standardized HTTP 422 Error Contract

Whenever a request fails schema validation, AtoZAPI intercepts the request before reaching your business logic and returns an HTTP 422 Unprocessable Entity response:

```json
{
  "detail": [
    {
      "loc": ["body", "age"],
      "msg": "Input should be greater than or equal to 18",
      "type": "greater_than_equal",
      "ctx": { "ge": 18 }
    },
    {
      "loc": ["body", "email"],
      "msg": "Input should be a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

## Ecosystem Comparison

| Framework | Package | Language Paradigm | Validation Hook |
| :--- | :--- | :--- | :--- |
| **Node.js (Express)** | `@atozapi/express` | Express Middleware | `app.post('/api', atozapi(schema), handler)` |
| **Next.js App Router** | `@atozapi/nextjs` | Higher-Order Handler | `export const POST = nextAtozapi({ schema, handler })` |
| **Go (Gin)** | `github.com/dhirajparihar/AtoZAPI/sdk-go/gin` | Gin Middleware + Generics | `r.POST('/api', ginatozapi.Guard(Req{}), handler)` |
| **PHP (Laravel)** | `atozapi/laravel` | PHP 8 Attributes + Reflection | `#[Post('/api', rules: [...])]` |
