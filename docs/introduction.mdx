# Fastapify Overview

FastAPI revolutionized the Python backend ecosystem with two defining features: **declarative runtime request validation** and **instant interactive OpenAPI/Swagger UI documentation at `/docs`**.

Until now, developers using Node.js (Express), Next.js, Go (Gin), or PHP (Laravel) were forced to either write hundreds of lines of fragile boilerplate JSDoc/Swagger comments, maintain desynchronized manual YAML specs, or bolt together incompatible third-party libraries.

**Fastapify eliminates that friction.** It delivers FastAPI's DX across every major backend environment without vendor lock-in or heavyweight runtime overhead.

<Note>
**The Fastapify Guarantee**: Write standard endpoint logic with native language types or schema definitions. Fastapify handles runtime validation, throws standard HTTP 422 errors on invalid input, and automatically compiles production-ready OpenAPI 3.0 documentation.
</Note>

## Ecosystem Matrix

Fastapify provides first-class support for the following backend ecosystems:

| Framework | SDK Package | Validation Engine | Documentation Hook |
| :--- | :--- | :--- | :--- |
| **Node.js (Express)** | `@fastapify/express` | Lightweight Schema Engine | `fastapify(schema)` middleware |
| **Next.js App Router** | `@fastapify/nextjs` | Web Stream Evaluator | `nextFastapify({ schema, handler })` |
| **Go (Gin)** | `github.com/dhirajparihar/FastAPIfy/sdk-go/gin` | Struct Reflection & Validator v10 | `ginfastapify.Guard(Struct{})` |
| **PHP (Laravel)** | `fastapify/laravel` | Native PHP 8 Reflection & Validator | `#[Post(path, rules: [...])]` |

## The Architecture at a Glance

```text
[ Incoming Request ]
         │
         ▼
[ Fastapify Guard / Middleware ]
         │
         ├─► Invalid? ──► HTTP 422 Unprocessable Entity ({ detail: [...] })
         │
         ▼ (Valid)
[ Route Handler (req.validatedBody) ]
```

Simultaneously, the **Fastapify CLI** scans your codebase at build or dev time to compile an `openapi.json` contract and serve interactive Swagger UI documentation at `/docs`.
